# prompt-layers（提示词分层 · 参考示例）

这个目录是本 bot 实际在用的分层提示词的一份**参考示例**，供他人部署时照着改，不是必须原样使用的配置。

## 分层结构

| 文件 | 层 | 作用 |
|---|---|---|
| `L0-base.md` | L0 底座 | 身份诚实、安全底线、层间优先级。稳定不变，放最前（利于上游缓存） |
| `L1-expression.md` | L1 表达规范 | 输出格式硬约束：长度、口语化、禁客服腔、禁 Markdown 等 |
| `L2-character-xiaoqian.md` | L2 角色层 | 人设示例「小千」——温柔大小姐、AI 身份坦承、边界话术。**换角色只改这一层** |
| `layers.mjs` | 拼装器 | 把 L0+L1+L2+L3+记事本规矩+收尾提醒拼成 system prompt；L3 能力层由实际注册的工具表**自动生成**，保证"说出来的能力"与"真有的工具"永远一致；`renderRuntime()` 生成每轮注入的 L4 运行时上下文（群名/时间/发言者/身份/记事/群聊缓冲/指代标注） |

## 使用与替换

- `config.mjs` 的 `layersDir` 默认指向本目录；要用自己的提示词，设环境变量 `LAYERS_DIR=<你的目录>`（目录里需要有 `layers.mjs` 与 `L0/L1/L2` 文件）。
- 换人设：复制本目录，改 `L2-character-*.md`，并在 `config.mjs` 的 `character` 里填新文件名。
- 改能力话术：不要手写 L3——它由 `config.mjs` 的 `tools`/`chatTools` 生成，改工具表即可。
- 拼装约定：稳定层在前（可缓存），易变内容不进 system、由 `renderRuntime()` 贴到用户消息尾部。改提示词结构时保持这个顺序。

## 注意

- 这些文件会被**原样拼进系统提示词**，不要在 MD 里加"这是示例"之类的元注释（会进模型上下文）；说明写在本 README 即可。
- 示例中的限额（60 字 3 句、每人 15/分 500/天、每小时 90 条等）是针对 QQ 群聊场景的调参结果，部署到其他场景请按需要调整 `config.mjs`。
